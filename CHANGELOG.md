# Release notes

## 1.00

Initial public release.

- Customize TUNE, poly TUNE, METER, header, footer and startup animation.
- Set different background images for different pages.
- Use your own note font and choose a tuning meter style.
- Preview and upload themes with the desktop app or command line.
- Share a theme as one `.pdui` file, including its images and note font.
- Includes examples, drawing API documentation and the USB uploader.

GAME and Settings keep their built-in appearance.
